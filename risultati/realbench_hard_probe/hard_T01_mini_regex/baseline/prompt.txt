TASK: Mini Regex Engine (match + find, greedy, backtracking-safe)

Implement a small regular-expression engine in `regex.py`.

SPEC:
- class Regex:
    - __init__(self, pattern: str) — compiles the pattern.
      Raises ValueError for invalid patterns.
    - match(self, text: str) -> bool
      True iff the WHOLE text matches the pattern.
    - find(self, text: str) -> list[str]
      All non-overlapping matches, scanned left to right, greedy
      (leftmost-longest). Semantics of empty matches: an empty match at
      position i contributes "" and advances by one character.
      Example: Regex("a*").find("b") == ["", ""]

PATTERN GRAMMAR (no anchors, no groups):
- atom: a literal character (any char EXCEPT: . ^ $ [ ] * + ? \)
- "." matches any single character except newline
- escape "\x" where x is one of: . ^ $ [ ] * + ? \ n t
  (\n = newline, \t = tab; any other escape → ValueError)
- character class "[...]":
    - contains characters and ranges "a-z"; a leading "^" negates
    - inside a class, "\" escapes the next char (e.g. "\]", "\-", "\\")
    - "]" must be escaped inside a class
    - empty class "[]" or "[^]" → ValueError
    - descending range "z-a" → ValueError
- quantifier after an atom or class: "*" (0+), "+" (1+), "?" (0 or 1)
- a quantifier at the start of the pattern, or directly after another
  quantifier → ValueError
- "^" and "$" are plain literal characters in this engine

PERFORMANCE REQUIREMENT: matching must be safe against catastrophic
backtracking — the pattern "a*a*a*a*a*b" against "a"*30 must return
False in under 2 seconds.

Standard library only. Do NOT import `re` — implement the engine yourself.
