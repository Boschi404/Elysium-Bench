Implement an LRU (Least Recently Used) cache in a single Python file `lru.py`.

SPEC:
- class LRUCache:
    - __init__(self, capacity: int) — capacity >= 1
    - get(self, key: int) -> int — returns the value, or -1 if key absent.

      used key before inserting a new key.
