- class TokenBucket:
    - __init__(self, capacity: float, refill_rate: float) -> None
      capacity = max tokens storable; refill_rate = tokens added per
      second. Both must be > 0, else ValueError.
    - try_acquire(self, n: float = 1.0, now: float | None = None) -> bool
      Attempts to consume n tokens (n >= 0). Returns True if enough tokens
      are available (consumes them), False otherwise (consumes nothing).
      Refill happens CONTINUOUSLY: tokens available at time t are computed
      from the last refill state plus elapsed*refill_rate, capped at
      capacity.
      `now` is a wall-clock timestamp in SECONDS (monotonic or epoch —
      your choice, but internally consistent). When `now` is None, use
      time.monotonic().
      All calls MUST be thread-safe: no lost refills or double-spends
      under concurrency.
    - available(self, now: float | None = None) -> float
      Current token count (refilled up to `now`), without consuming.

DETERMINISM: tests pass explicit `now` values (e.g. 0.0, 1.0, 2.5) and
expect EXACT amounts: tokens refill linearly with elapsed time.

after try_acquire(8) at t=0 → available 2; at t=3 (3s elapsed) → 2 + 6 = 8.
